# Frontend room integration contract

The room UI uses `RoomClient` with a local demo adapter by default. `NEXT_PUBLIC_ROOM_TRANSPORT=remote` opts into the proposed HTTP/Socket.IO integration; `NEXT_PUBLIC_ROOM_API_URL` and `NEXT_PUBLIC_ROOM_SOCKET_URL` default to same origin. No backend is supplied here. The local adapter and `/review` fixtures are browser-local and do not provide cross-browser multiplayer or a scoring engine. Fixture scores are presentation data.

Bootstrap uses `POST /api/rooms` with `{profile}`, `POST /api/rooms/:code/join` with `{profile}`, and `GET /api/rooms/:code/resume` with a bearer resume token. Responses contain a `RoomSession`; the token must never be placed in a URL. The public snapshot must omit target words and unrevealed AI answers; drawer-only target data is separately delivered in private state. Session credentials live in session storage.

The socket is created with `autoConnect: false` only after successful bootstrap. Commands are `room:settings`, `room:move`, `room:select-team`, `room:start`, `room:leave`, `room:chat`, `room:guess`, `room:drawing`, and `room:resync`. A command envelope carries requestId, expectedRevision, generation and payload; server acknowledgements return `{ok, code?, message?}`. These names and payloads are proposed integration contracts, not a running backend. The server must deduplicate request IDs, reject stale revisions/generations and send authorized data only.

`room:event` carries typed snapshot, connection, drawing, acknowledgement or gameplay events. Ignore stale snapshots. A drawing event identifies canvas and generation, includes its canonical sequence, and marks `reset` for complete replay or incremental operations otherwise. `caughtUp` is true only once the replay reaches the current stream boundary. The UI must await hydration before enabling drawer input. On reconnect request a complete resync. For an interrupted remote stroke, the backend must define and deliver an authoritative closure; clients do not invent remote operations. The local demo closes an interrupted persisted stroke deterministically before replay.

Settings enforce individual default, six seats and six prompt rounds; teams are explicit. Local examples do not establish hosting capacity, AI behavior, score calculation, or reliable real-time networking. Scoring semantics are governed by `BACKEND-SCORING-PLAN.md`, not older preview values.
